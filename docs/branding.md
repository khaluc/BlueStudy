# BlueStudy

The application is branded **BlueStudy** in Vietnamese and English: navigation,
page titles, accessible labels, chat, help, study tools, API titles, AI system
prompts and exported exam filenames.

Existing infrastructure identifiers (`padayon` database/user/Compose directory,
authentication cookie and browser storage keys) are retained for compatibility
with saved documents, sessions, language preferences and unfinished exam answers.
They are internal identifiers, not the product name. Original uploaded documents
and previously saved learner/AI content are not rewritten by a branding change.
